# BauDackel (React + JavaScript)

AI-powered construction documentation demo converted from Streamlit (`app.py`, `knowledge_hub.py`, `performance_monitoring.py`, `meeting_intelligence.py`) to React and JavaScript (Vite).

> **Note:** This demo uses dummy data and simulated responses only. It does not connect to an external AI service.

## Setup & Run

```bash
npm install
npm run dev
```

To create a production build:

```bash
npm run build
npm run preview
```

## Optional Brand Assets

If you want your `logo.png` and `mascot.png` from `../assets/` displayed in the sidebar and Project Assistant, copy them into `public/assets/`. If they are absent, clean built-in fallbacks are rendered automatically.
